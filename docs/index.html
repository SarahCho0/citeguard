Why this exists

If you verify an LLM with another LLM,
the verifier is also guessing.

Built from patterns shipped on two production AI systems — an enterprise product-matching engine and an investment-deliberation LLM engine — generalized into a public library. Three failure modes, three deterministic answers:

◈ Source hallucination

LLM reports cite files, pages, and quotes that don't exist. The Citation Gate string-matches every citation against the ingested corpus and blocks the report if any claim fails.

◎ Unmeasured retrieval

"It seems to find things" is not a metric. The Eval Harness scores Hit@K / MRR on a labeled set and diagnoses which pipeline stage lost the right answer.

◇ Silent drift

Prompt and parameter changes shift outputs quietly. Golden tests pin verified outputs and fail loudly — with an exact diff path — when anything moves.

04 · The Math

Guarantees derived from structure, not vibes.

Every verdict on this page is a deterministic function built on mathematical structure — documented in full in MATH.md, pinned by property tests in CI.

≅ Normalization = canonical forms

normalize() is an idempotent projection π (π∘π = π, pinned by a test). Comparing canonical representatives reduces "same sentence up to notation" to plain substring matching.

x ~ y ⟺ π(x) = π(y)

△ Edit distance is a metric

Symmetry, identity, and the triangle inequality are verified empirically by parametrized tests. The metric structure makes branch-and-bound window search provably exact — pruning cannot change the result.

|len(a) − len(b)| ≤ d(a,b) ≤ d(a,c) + d(c,b)

∝ BM25 = probability ranking

IDF is a smoothed Robertson–Spärck Jones odds ratio; term-frequency saturation is a bounded concave function — repeated tokens have diminishing returns, by design rather than accident.

idf·tf·(k₁+1) / (tf + k₁·(1−b+b·len/avg))

⊕ Golden diff = tree isomorphism

JSON outputs are ordered labeled trees; structural recursion decides equality — and for ordered trees, equality is isomorphism. Every regression carries its exact root-to-leaf path.

$.final_rankings["…"][2]: "P009" → "P023"
